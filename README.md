# steane-qec-project
Stabilizer Syndrome Extraction Through the Lens of One-Bit QPE


Project Description: Use the [[7,1,3]] Steane code to study syndrome extraction from both the traditional stabilizer-measurement perspective and the one-bit quantum phase estimation perspective. Implement standard ancilla-based syndrome extraction circuits, reinterpret the same measurements as one-bit QPE applied to Pauli stabilizers, and verify the resulting syndromes for all single-qubit Pauli errors.

Represent Pauli operators and stabilizers using the binary symplectic formalism and use this representation to compute and verify syndrome information algebraically. The project will establish the stabilizer, syndrome, and symplectic machinery that will be reused in Project 2.
